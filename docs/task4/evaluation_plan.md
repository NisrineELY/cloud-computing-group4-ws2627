# Evaluation Plan

## Objective

Evaluate the performance, scalability, monitoring capability, and fault tolerance of the drone detection system.

---

# 1. Network Traffic Analysis

## Goal

Determine how much network traffic is generated by the system under different workloads.

## Metrics

- Average network throughput
- Peak network throughput
- Traffic per camera
- Traffic per detection event

## Tools

- Prometheus
- Grafana
- Wireshark
- tcpdump

## Test Scenarios

### Scenario A: Idle System

No drone detections.

### Scenario B: Normal Operation

Regular camera activity and occasional detections.

### Scenario C: Heavy Activity

Continuous detections and data transfer.

---

# 2. Backend Throughput Evaluation

## Goal

Determine maximum event processing capacity.

## Metrics

- Events per second
- Messages per second
- Database writes per second
- API requests per second

## Test Method

Generate increasing numbers of detection events.

Example:

- 10 events/sec
- 50 events/sec
- 100 events/sec
- 500 events/sec

Observe when performance degradation occurs.

---

# 3. Resource Utilization Evaluation

## Goal

Measure resource consumption of system components.

## Metrics

### Sensor Node

- CPU utilization
- RAM utilization
- Temperature
- Network usage

### Backend

- CPU utilization
- RAM utilization
- Storage consumption
- Queue utilization

## Test Conditions

### Idle

No active detections.

### Normal Load

Typical operating conditions.

### Stress Load

Maximum event generation.

---

# 4. End-to-End Latency Evaluation

## Goal

Measure total processing delay.

## Evaluation Path

Camera
→ Detection
→ Message Queue
→ Backend
→ Dashboard

## Metrics

- Minimum latency
- Average latency
- Maximum latency

## Unit

Milliseconds (ms)

---

# 5. Fault Tolerance Evaluation

## Goal

Verify that failures are detected and reported.

## Scenarios

### Camera Failure

Expected:
- Dashboard alert
- Telegram notification

### Sensor Node Restart

Expected:
- Offline event detected
- Recovery detected

### Network Failure

Expected:
- Connectivity warning

### Backend Service Failure

Expected:
- Service alert

### Storage Failure

Expected:
- Storage warning

---

# Success Criteria

- All failures detected
- Telegram notifications delivered
- Dashboard updated correctly
- System performance measurements recorded
- Evaluation results documented
